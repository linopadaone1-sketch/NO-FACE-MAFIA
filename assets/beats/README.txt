Ce dossier est prévu pour accueillir tes vrais fichiers audio de beats
(.mp3).

Pour l'instant, le bouton Play du site génère un son de démonstration
directement dans le navigateur (pas de vrai fichier). Quand tu auras
tes fichiers MP3, dépose-les ici (par exemple : ombre-urbaine.mp3) et
on modifiera ensemble le code pour que le bouton Play lise ces vrais
fichiers au lieu du son de démonstration.

Ce dossier est prévu pour accueillir tes vraies images de covers
(covers de beats, covers d'albums/EPs, photos d'artistes...).

Formats conseillés : .jpg ou .png, carré (par exemple 800x800 pixels),
poids léger (moins de 500 Ko par image si possible pour que le site
reste rapide).

Pour l'instant, le site génère des covers automatiquement (formes et
lettres) directement dans le code, donc tu n'es pas obligé de remplir
ce dossier tout de suite. On branchera tes vraies images ici à une
prochaine étape.

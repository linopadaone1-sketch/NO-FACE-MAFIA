# NO FACE MAFIA — Site vitrine

Site vitrine du label/collectif NO FACE MAFIA : présentation, écoute des
beats, section artistes, section projets et contact.

## Structure du projet

```
no-face-mafia/
├── index.html          → la page du site (tout est dans ce fichier : HTML, CSS, JS)
├── assets/
│   ├── covers/          → à remplir plus tard avec les vraies images de covers
│   └── beats/           → à remplir plus tard avec les vrais fichiers MP3
└── README.md            → ce fichier
```

## Déploiement

Ce site est 100% statique (aucun serveur, aucune base de données requise).
Il est hébergé gratuitement avec GitHub Pages.
